Resources / Hooks

block-dangerous-commands

hookPreToolUseoursall stacks

Stops Claude before it runs a force push, a hard reset, a broad recursive delete or a DROP TABLE, and tells it why.

Install

New-Item -ItemType Directory -Force .claude\hooks
Copy-Item block-dangerous-commands.mjs .claude\hooks\

What it does

Runs before every Bash or PowerShell tool call. If the command matches a dangerous pattern, it exits with code 2. Claude Code cancels the call and shows Claude the reason, so it can pick a safer path.

Example

You ask Claude to "clean up the branch". It tries git reset --hard origin/main. The hook blocks it: "hard reset discards uncommitted work. Ask the user first."
